# Diseño de materiales de aprendizaje

## Formatos
- A4 vertical: 210×297 mm, márgenes 16–20 mm, cuerpo 10.5–12 pt.
- Presentación PDF horizontal: 16:9, por ejemplo 960×540 pt, márgenes 32–40 pt, cuerpo 18–24 pt.
- A4 apaisado a pedido: 297×210 mm.
- Mantener una idea central por página o bloque, jerarquía de títulos y espacio entre grupos. Dividir contenidos largos antes de reducir tamaños.

## Visuales
Usar una familia de iconos vectoriales coherente, acompañados de etiquetas cuando sean ambiguos. Emplear tablas para diferencias, cronologías para fechas, flujos para procesos y mapas para conceptos relacionados. Etiquetar relaciones; respetar sentido, secuencia y unidades. No dibujar gráficos de datos con generación de imágenes.

Conservar la relación de aspecto de fotos y capturas y añadir pie de fuente. Usar ampliaciones con contexto para pantallas densas. Las marcas puntuales no deben tapar información. Las ilustraciones 2D o 3D sirven para apoyar conceptos, no para representar como real una evidencia inexistente.

## Pedagogía y accesibilidad
Alinear estructura a objetivos y nivel del estudiante. Explicar vocabulario nuevo, destacar sin depender solo del color y evitar párrafos sobre imágenes complejas. Separar consignas y soluciones. Usar contraste suficiente y texto seleccionable; no codificar diferencias únicamente mediante colores.

## Revisión
Renderizar todas las páginas. Comprobar acentos y símbolos, orden de lectura, contraste, fuentes, márgenes, encabezados, tablas sin cortes y correspondencia entre conceptos y diagramas. No confundir una paráfrasis con una cita ni agregar bibliografía ficticia.
